# TEA Skills

Agent skills for **The Experience Advantage (TEA)** — mentor-not-guru tools for encore entrepreneurs turning 20+ years of expertise into AI-powered income streams.

Built and maintained by [Art Fogelstrom](https://github.com/Afoge844). Skills follow the [agentskills.io](https://agentskills.io) spec and install across Claude Code, Cursor, Codex, Gemini CLI, and GitHub Copilot.

## Skills

| Skill | Purpose |
|-------|---------|
| [`grill-me`](./skills/grill-me) | Relentless one-question-at-a-time interview to pressure-test a plan, offer, or launch decision until every branch is resolved. |
| [`handoff`](./skills/handoff) | Compact a session into a structured handoff doc so the next session (or agent) can resume without re-explaining context. Built for ADHD-aware Saturday batch workflows. |

## Install

```bash
gh skill install Afoge844/tea-skills grill-me
gh skill install Afoge844/tea-skills handoff
```

Pin to a specific version:

```bash
gh skill install Afoge844/tea-skills grill-me@v1.0.0
```

## Credits

`grill-me` and `handoff` are TEA-voiced adaptations of patterns originally published in [mattpocock/skills](https://github.com/mattpocock/skills). The mentor-not-guru framing, decision-tree logic, and Saturday-batch handoff structure are tuned for the TEA workflow.
